# Vontec - Identidade Visual Renovada 2026

Este projeto apresenta a nova cara da **Vontec**, inspirada no minimalismo e na precisão técnica do **Claude Code**.

## Conceito: "The Tech Pulse"
A nova identidade foca em:
- **Contraste Profundo:** Uso de pretos obsidianos (`#0a0a0c`) para passar autoridade e sofisticação.
- **Acento Indigo:** A cor principal (`#6366f1`) traz a energia da inovação e remete à paleta moderna de ferramentas de IA.
- **Geometria Pura:** O novo logo simplifica o 'V' de Vontec, integrando um ponto de pulso tecnológico.

## O que foi criado:
1.  **Pasta `Vontec_Renovated/`**: Contém os novos arquivos.
2.  **`index.html`**: Uma Landing Page completa que serve tanto como vitrine da marca quanto como site institucional.
    -   Design Responsivo.
    -   Modo Escuro nativo.
    -   Tipografia limpa (Inter).

## Como Visualizar:
Basta abrir o arquivo `index.html` em qualquer navegador moderno.
